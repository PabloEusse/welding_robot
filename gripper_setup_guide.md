# Robot Gripper Setup Guide

## Initial Setup

1. Open web browser and navigate to `http://192.168.1.20/`
2. Go to **Motion** → **Manual Control**
3. Configure the following parameters:
   - **Force Limit:** 80 N
   - **Speed:** 50 mm/s
   - **Width:** 35.7 mm
4. Insert the welding gripper into the gripper
   - If possible, apply tape on the gripping points for better grip

## Troubleshooting

### 1. Initialization Error

**Try first:**
1. Navigate to **Motion** → **Manual Control**
2. Select **Home** to bring the robot to home position

**If that doesn't work:**
- Restart the robot → **System** → **System** → **Restart System**  OR if this doesnt work Pull out the cable and restart it that way(not robot ones, Gripper has seprate one) 

### 2. Access Denied Error

**Solution:**
- Restart the robot → **System** → **System** → **Restart System**  OR if this doesnt work Pull out the cable and restart it that way(not robot ones, Gripper has seprate one)
